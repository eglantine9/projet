Algo_génétique module¶

Algo_génétique.fusion(matrice, pond)[source]¶

merge different weighted vectors together

Parameters:

  • matrice (numpy.array) – matrice of all the vectors, number of row correspond to the number of vectors to fuse

  • pond (numpy.array or list) – vector containing to the weights of each vector in the same order as the matrice

Returns:

new_image – New vector computed by the weighted merge

Return type:

numpy.array

Examples

>>> fusion(np.array([[0.5,0.8,0.2,0.6,0.7],[0.4,0.7,0.1,0.5,0.8]]), (1,2))
[0.43333333 0.73333333 0.13333333 0.53333333 0.76666667]
